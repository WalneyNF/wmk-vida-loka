WMK Avatar Lab 2.0 — v2.7

Walney Moreira Klein — walneyk@hotmail.com

Guia de primeiro contato, intermediário e técnico para personagens modulares 2D.

1. Camadas

O desenho vetorial de cima continua presente. Quatro sobreposições PNG são renderizadas na ordem Corpo → Roupa → Cabeça → Equipamento. Sprites transparentes mostram o desenho abaixo.

2. Importação

  1. Abra Avatar Lab no menu principal.
  2. Expanda Camadas de sprites PNG e clique em Importar sprite PNG.
  3. Escolha um PNG transparente menor que 350 KB, preferencialmente 64×64 ou 128×128, com a parte centralizada.
  4. O arquivo entra na biblioteca e é selecionado inicialmente como Roupa; altere a camada pelo seletor.
  5. Salve o avatar para jogar ou guarde um perfil para reutilizar em bots.

3. Animação

Escolha Parado, Caminhada, Corrida ou Disparo. Ajuste a velocidade de 1 a 12, pause ou avance um quadro. A animação é procedural: não há keyframes nem spritesheet animada na v2.7.

4. Atribuir o avatar a um bot

  1. Guarde o perfil no Avatar Lab.
  2. Abra Bot Lab; selecione um bot.
  3. Escolha o perfil no campo Avatar e salve o bot.
  4. Inicie o mapa para ver o sprite aplicado.

5. Formato JSON

{
  "format":"wmk-vida-loka-avatar",
  "version":2,
  "avatar":{
    "name":"Agente WMK",
    "spriteLayers":{"body":"","clothes":"asset-avatar-001","head":"","gear":""},
    "animationSpeed":6
  },
  "assets":[{"id":"asset-avatar-001","name":"roupa.png","data":"data:image/png;base64,..."}]
}

O exemplo é ilustrativo. Dados reais devem conter a imagem completa.

6. Limitações

Biblioteca limitada a 30 imagens; use PNGs leves e exporte backup, pois localStorage tem cota. A prévia mostra sobreposições em vez de substituir todas as partes físicas do corpo. O teste de persistência real entre sessões no Windows continua pendente.

7. Exercícios

  1. Crie um policial com roupa e capacete.
  2. Importe um sprite de acessório PNG para Equipamento.
  3. Guarde o perfil e aplique a um aliado.
  4. Exporte o avatar em JSON v2, limpe as camadas e reimporte para testar a recuperação.
