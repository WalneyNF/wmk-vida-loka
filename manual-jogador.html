Como começar

Abra index.html no navegador ou sirva a pasta pelo XAMPP. Escolha um dos mapas: Baía Nova, Costa Dourada, Serra Brava e Terminal Zero. Use WASD, Shift para correr, E para veículos, Espaço para freio de mão; na arena, mouse para mirar e disparar, R para recarregar.

Editor de mapas passo a passo

  1. Abra World Studio pelo menu principal.
  2. Selecione um mapa e clique Duplicar para preservar o original.
  3. Insira prédios, árvores, barreiras, sprites ou bots.
  4. Selecione objetos; G move, S escala, R gira. Arraste as alças coloridas. Ctrl+Z desfaz, Ctrl+Y refaz.
  5. Ative a grade, salve e exporte JSON para backup.

Novos recursos de terreno e colisões

Selecione Pincel de terreno, ajuste cor e tamanho e clique no mapa para criar blocos coloridos. Marque Mostrar colisões para ver áreas sólidas. Selecione um objeto e pressione Salvar objeto selecionado na biblioteca para reutilizá-lo em outro mapa.

Pincel simples, sem autotile ou atlas de tiles.

Bots e rotas visuais

  1. Escolha um bot existente pelo mapa ou lista.
  2. Escolha Rota de patrulha do bot.
  3. Clique sequencialmente no mapa para adicionar waypoints.
  4. No Bot Lab defina equipe, dano, arma, vida e avatar.
  5. Teste o mapa. Bots na arena usam navegação A* básica.

Avatar Lab e Bot Lab

No Avatar Lab configure roupa, cabelo, acessórios e cores, e clique Guardar perfil. Use Carregar perfil para recuperá-lo. Depois, no Bot Lab, selecione o perfil no campo Avatar visual e salve o bot.

Missões e pacotes Game Creator

No Editor de Missões crie objetivos, recompensa W$ e escolha quais mapas aceitam a missão. Visualizar fluxo de objetivos mostra a sequência. Em Criar Meu Jogo, escolha mapas e missões e exporte pacote JSON. Também é possível importar pacotes JSON compartilhados. O pacote funciona dentro do motor WMK; não é um executável.

Importação de recursos externos

World Studio importa imagens PNG/JPG/WebP. Para modelos 3D, renderize uma visão superior como sprite. O Canvas 2D não suporta GLB/FBX nativamente. Verifique a licença de cada pacote gráfico.

Salvamento e solução de problemas

Faça backups JSON frequentemente. Dados do navegador podem ser apagados e imagens ocupam armazenamento. Consulte F12/Console para mensagens de erros. A persistência real depende das políticas do navegador e da origem.
