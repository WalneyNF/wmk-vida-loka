Manual do Jogador — mapas, objetos e missões

JogoManual do jogadorManual do desenvolvedorPesquisaRoadmap

Este manual ensina a jogar, escolher um mapa, usar os editores, criar objetos com colisões, importar sprites externos e compartilhar seus cenários. Versão 1.3.0.

1. Primeira partida

1. Abra index.html em Chrome, Edge ou Firefox. Se o navegador bloquear recursos, execute servidor local (consulte manual do desenvolvedor).
2. No menu principal, clique em Selecionar no cartão de um mapa e depois em Jogar mapa selecionado, ou clique em Jogar no próprio cartão.
3. Use W/A/S/D para movimentar, Shift para correr, E para entrar/sair do carro, Espaço para freio de mão e ESC para voltar ao menu.

3. Criar um mapa

No menu principal, clique Editor de Mapas → Novo mapa. Preencha nome, descrição e escolha cor do terreno. Selecione uma ferramenta à esquerda (árvore, prédio, água, areia, barreira, decoração ou sprite) e clique na área central para adicionar. No painel direito, selecione um objeto e ajuste nome, X, Y, largura, altura, rotação, cor, camada e colisão. Clique Salvar mapa e depois Testar mapa.

4. Criar objetos e configurar colisões

Um objeto é desenhado em sua posição X/Y e possui dimensões, rotação e camada. Marque Ativar colisão para impedir o personagem e carros de atravessá-lo. Para areia, decoração e caminhos, normalmente desmarque colisão. Água ou prédio normalmente usam colisão ligada. O colisor é um retângulo orientado que acompanha a rotação. Teste se o personagem consegue chegar ao ponto inicial e a cada objetivo da missão.

5. Importar uma imagem da Kenney ou criada por você

1. Baixe um pacote de arte autorizado (ex.: Kenney Assets).
2. Localize ou exporte uma imagem individual PNG, JPG ou WebP. Modelos 3D (.glb, .gltf, .obj) não são importados diretamente nesta versão; renderize-os como sprites 2D primeiro.
3. No Editor de Mapas, clique Importar PNG/JPG/WebP (até 750 KB).
4. Selecione a imagem na biblioteca, escolha a ferramenta Sprite importado e clique no mapa.
5. Em propriedades, configure largura, altura, rotação, camada e colisão. Salve e teste.
Os pacotes Kenney não vêm incluídos. Verifique sempre a licença de cada pacote e mantenha os créditos quando exigidos. Sprites importados são armazenados localmente no navegador e podem ocupar bastante espaço.

6. Compartilhar mapas (JSON)

Use JSON no editor para exportar um mapa com seus objetos e sprites usados; use Importar JSON no mesmo editor para recuperá-lo. Para compartilhar todos os mapas + missões + biblioteca, no menu clique Exportar projeto JSON. O botão Importar projeto JSON substitui os dados locais após confirmação: faça backup antes.

7. Criar e associar missões a mapas

No menu principal abra Editor de Missões. Escolha uma missão para modificar ou crie uma nova. Defina título, descrição, tipo, recompensa em W$, pontos de objetivo (uma coordenada x,y por linha) e, se necessário, marque exigir veículo. Em Mapas permitidos, coloque IDs separados por vírgula (por exemplo baia-nova, serra-brava); deixe vazio para uma missão aparecer em todos os mapas. Defina modo livre, corrida, entregas, exploração ou polícia. Salve e teste.

As missões atuais usam o mecanismo simples de pontos e gatilhos; cronômetro, diálogos, requisitos complexos, NPCs e editor de objetivos por clique são evoluções futuras. O modo selecionado é metadado para organização e expansão, não um simulador completo de cada gênero.

8. Dicas e problemas comuns

  • Se o objeto importado não aparecer, verifique se escolheu a ferramenta Sprite e selecionou a imagem na lista.
  • Se ficar preso, desative a colisão do objeto, mova a posição inicial ou reposicione o objeto.
  • Se aparecer erro de espaço, reduza tamanho e quantidade dos sprites e exporte um backup JSON.
  • Se uma missão não aparecer, confira os IDs no campo Mapas permitidos e se há pontos válidos.
  • Se você criar um mapa novo, ele fica salvo apenas neste navegador até ser exportado.

Novidades v1.5 — Gizmos e World Studio

No menu abra World Studio e selecione um objeto ou bot clicando na cena ou pela lista. G move por alças vermelha (X) e azul (Y). S escala objetos pela alça verde; R gira objetos pela alça roxa. Bots têm movimentação, mas não escala/rotação individual. Marque Grade 25 para alinhamento. Ctrl+Z desfaz e Ctrl+Y refaz operações na cena.

O Editor de Missões agora tem uma tela separada com regras avançadas expansíveis. Para um tutorial com exercícios, limites e planejamento, consulte Guia de evolução v1.5.

Atualização v1.6 — Bots, Objetos e Armas

Seleção de bot: World Studio → Ferramenta → Inserir bot. A janela mostra cartões 🔴 Inimigo, 🔵 Aliado e ⚪ Neutro, com nome, equipe, arma, comportamento e HP. Clique no tipo desejado, depois no mapa, e use o gizmo G para mover.

Editor de Objetos: abra no menu principal; crie modelo com tipo, dimensões, cor, colisão, sprite opcional e camada. Salve e no World Studio escolha a ferramenta «Objeto da biblioteca» para inserir. Modifique instâncias com G/S/R. Cada mapa pode ser duplicado e editado.

Editor de Armas: abra pelo menu principal; crie arma fictícia configurando dano, alcance, cadência, capacidade e precisão. No Bot Lab escolha a arma para preencher os atributos do bot. A cadência influencia os tiros da IA; a capacidade ainda não implementa recarga do bot.

Use Exportar JSON em cada editor e Exportar Projeto no menu para cópias de segurança. As bibliotecas são gravadas localmente no navegador, não em uma conta online.

◉ WMK Avatar Lab — v1.7

Menu principal → EDITOR DE AVATAR. Personalize nome, porte corporal, cabelo, boné/capacete, mochila e cores. A pré-visualização aparece à direita, em Canvas, com o personagem visto de cima.

Salvar avatar aplica a aparência ao jogador em todos os mapas. Exportar JSON gera um backup; Importar JSON preenche a prévia e exige clicar em Salvar. O botão Exportar Projeto também inclui o avatar.

Exemplo JSON: {"format":"wmk-vida-loka-avatar","version":1,"avatar":{"name":"Jogador","body":"regular","hair":"short","hat":"cap","backpack":"pack","skin":"#f2c6a1","shirt":"#50d6a8","pants":"#213740","hairColor":"#342722","hatColor":"#d1b260","packColor":"#5a8191"}}

Para desenvolvedores: funções safeAvatar() (validação), paintAvatar() (desenho), renderAvatarPreview() (prévia); persistência local pela chave wmk-vida-loka-avatar-v1. Não executa scripts de arquivos importados. O formato do corpo modifica apenas o visual, sem alterar colisões nem atributos.

Exercício: crie três avatares, exporte JSON e importe outro modelo. Próximos passos: skins PNG, animações, múltiplos personagens e compartilhamento de visuais com NPCs.
