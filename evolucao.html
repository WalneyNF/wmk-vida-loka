2. Exercício: transforme Terminal Zero

  1. No menu abra World Studio e selecione Terminal Zero.
  2. Use Duplicar mapa para não alterar o original. Renomeie para Terminal da Serra.
  3. Escolha Barreira e clique para criar uma cobertura; mude para Selecionar/mover.
  4. Selecione a barreira no canvas ou na lista. Pressione G e arraste a alça vermelha para X, azul para Y, ou centro para mover livre.
  5. Pressione S, arraste a alça verde para aumentar sua largura e altura. Pressione R e arraste a alça roxa para rotacioná-la.
  6. Marque Grade 25 para facilitar alinhamento. Use Ctrl+Z e Ctrl+Y para desfazer/refazer.
  7. Escolha Inserir bot e clique no mapa. O bot ficará selecionado; mova-o usando G. Clique em Editar bot no Bot Lab para definir arma, equipe, dano e patrulha.
  8. Altere a propriedade Colisão dos obstáculos. Salve, teste o mapa e exporte o JSON para backup.

Limite atual: a colisão usa volumes simplificados; cheque a passagem do personagem após grandes rotações.

3. Exercício: missão customizada

  1. No menu abra Editor de Missões. Clique em Criar.
  2. Defina título, descrição, tipo e recompensa em W$.
  3. Informe marcadores no formato X,Y, um por linha. No campo de mapas permitidos, use o ID do mapa ou deixe vazio para todos.
  4. Expanda Regras avançadas para escolher vitória por marcadores, eliminação ou sobrevivência; defina equipe e tempo.
  5. Salve, teste, revise e exporte JSON.
{
  "id": "resgate-terminal",
  "title": "Contrato do Terminal",
  "points": [[450,450],[850,650]],
  "maps": ["terminal-zero"],
  "reward": 450,
  "goal": "points"
}

Exemplo ilustrativo de campos: use a exportação do editor para obter o esquema integral.

6. Como testar

Execute python testes/test_smoke.py e python testes/test_gizmos.py com Playwright e Chromium. Foram aprovadas 39 verificações da suíte antiga, 13 novas e um teste adicional de desfazer/refazer. Teste também manualmente sprites externos, colisões após rotações, armazenamento HTTP e desempenho.

Recursos para estudo: Canvas API, Playwright Python e Kenney Top-down Shooter (verificar licença dos assets antes de redistribuir).

Atualização v1.6 — Bots, Objetos e Armas

Seleção de bot: World Studio → Ferramenta → Inserir bot. A janela mostra cartões 🔴 Inimigo, 🔵 Aliado e ⚪ Neutro, com nome, equipe, arma, comportamento e HP. Clique no tipo desejado, depois no mapa, e use o gizmo G para mover.

Editor de Objetos: abra no menu principal; crie modelo com tipo, dimensões, cor, colisão, sprite opcional e camada. Salve e no World Studio escolha a ferramenta «Objeto da biblioteca» para inserir. Modifique instâncias com G/S/R. Cada mapa pode ser duplicado e editado.

Editor de Armas: abra pelo menu principal; crie arma fictícia configurando dano, alcance, cadência, capacidade e precisão. No Bot Lab escolha a arma para preencher os atributos do bot. A cadência influencia os tiros da IA; a capacidade ainda não implementa recarga do bot.

Use Exportar JSON em cada editor e Exportar Projeto no menu para cópias de segurança. As bibliotecas são gravadas localmente no navegador, não em uma conta online.
