Atlas PNG e pintura

  1. Abra o Editor de Mapas no menu.
  2. Importe um PNG pelo botão Importar PNG/JPG/WebP (até 750 KB).
  3. Escolha o arquivo em Sprite (biblioteca).
  4. Em Atlas PNG, informe quantas colunas e linhas regulares possui a imagem.
  5. Clique em uma célula da prévia ou informe seu índice a partir de 0.
  6. Escolha o tamanho do pincel e clique em Pintar célula selecionada; clique no mapa.
  7. Salve e exporte o JSON do mapa.

Exemplo: atlas de 256×256 pixels com 4 colunas por 4 linhas = 16 células de 64×64. Arquivos TMX/TSX e atlas irregulares ainda não são suportados.

Painéis móveis

  1. Ative Painéis flutuantes na barra do World Studio.
  2. Arraste pela faixa ☷ superior de cada painel.
  3. Redimensione pelo canto inferior direito.
  4. Use ↺ Layout para restaurar as posições.
  5. Desative Painéis flutuantes para retornar à disposição clássica.

As posições são salvas no armazenamento local do navegador, mas a persistência real entre reinicializações ainda precisa de teste em Windows.

Bots e abrigo

Bots feridos, que não sejam guardas, tentam encontrar uma posição protegida por obstáculos sólidos quando a vida fica abaixo de 35%. O comportamento é experimental e utiliza a navegação A* existente. Não implementa agachamento, reservas de cobertura ou busca tática avançada.

Formato JSON

{ "type": "sprite", "assetId": "asset-123", "atlasCols": 4, "atlasRows": 4, "atlasIndex": 7, "w": 100, "h": 100, "solid": false }

Mapas antigos sem estas propriedades continuam compatíveis, usando uma imagem única.
