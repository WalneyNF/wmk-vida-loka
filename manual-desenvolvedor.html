Guia técnico e prático para estender o WMK Vida Loka v1.4.0. Público: quem conhece HTML, CSS, JavaScript e JSON ou deseja começar a programar o projeto.

1. Arquitetura atual

O jogo usa Canvas 2D + JavaScript sem framework, entrada de teclado, loop de atualização com requestAnimationFrame, renderização, sistemas de jogador, veículo, polícia e missões. O editor e o menu também são implementados em index.html. Essa estrutura funciona para protótipos mas deverá ser modularizada na próxima refatoração.

2. Rodar e depurar

# No Windows, na pasta do projeto:
py -m http.server 8000
# Abra http://localhost:8000/ no navegador
# F12 → Console para erros e Network para imagens/JSON

Não é necessário npm nem build. Teste em Chrome e Edge; a persistência pode variar entre file:// e http://localhost.

3. Modelo JSON de mapa

{
 "id":"meu-bairro", "name":"Meu Bairro", "description":"Bairro feito por mim",
 "background":"#596e58", "theme":"custom", "spawn":[255,120],
 "roadsX":[160,760,1360],"roadsY":[150,650,1150],
 "objects":[{"id":"galpao-1","name":"Galpão","type":"building",
   "x":850,"y":400,"w":160,"h":110,"rotation":0,
   "color":"#65777b","solid":true,"layer":1,"assetId":""}]
}

Dimensões são unidades internas do mundo, não metros reais. O mundo base mede 2720 × 2300 unidades. Objetos são posicionados pelo centro; rotation usa graus. Os limites de importação são aplicados por sanitizeMap(). Tipos: building, tree, water, sand, barrier, decoration, sprite.

4. Geometria e colisão

Colisões são tratadas por círculos (personagem e carro) contra retângulos rotacionados (objetos): o ponto é transformado para o espaço local do objeto, limitado à caixa, e comparado ao raio. O protótipo original também considera edifícios gerados. Esta é uma aproximação geométrica; ainda não existe física contínua, formas poligonais, colisões entre veículos ou separação por materiais.

const angle = object.rotation * Math.PI / 180;
const dx = player.x - object.x, dy = player.y - object.y;
const localX = dx * Math.cos(angle) + dy * Math.sin(angle);
const localY = -dx * Math.sin(angle) + dy * Math.cos(angle);
// Em seguida: ponto mais próximo no retângulo local e teste de distância.

5. Sprites externos e Kenney

No editor, imagens individuais PNG/JPG/WebP são convertidas com FileReader para Data URL e guardadas como biblioteca local de assets. Cada sprite no mapa usa assetId em vez de guardar imagem duplicada por objeto. O desenho usa Image() + drawImage(). Um pacote 3D Kenney exige exportação prévia para imagens 2D, por exemplo usando Blender com câmera ortográfica superior. Não há importador nativo de GLB/GLTF/OBJ nem suporte a SVG externo nesta versão.

"objects":[{
  "id":"carro-decorativo", "name":"Sprite do carro", "type":"sprite",
  "x":600,"y":200,"w":70,"h":40,"rotation":0,"layer":2,
  "color":"#ffffff", "solid":true, "assetId":"asset-123"
}]

Para compartilhar os sprites corretamente, use a opção exportar mapa ou projeto do editor: o exportador inclui os dados da biblioteca usados. Os arquivos de imagem individuais não são copiados automaticamente para o repositório GitHub.

6. Missões por mapa

{
 "id":"corrida-serra", "title":"Rali da Serra", "description":"Passe nos pontos",
 "type":"race", "mode":"corrida", "reward":900,
 "maps":["serra-brava"], "points":[[160,150],[760,650],[1360,1150]],
 "vehicle":true
}

maps: [] significa todos os mapas. Uma lista com um ou mais IDs limita a disponibilidade. A lógica atual é sequencial por coordenadas e pode ser estendida com objectives, prerequisites, triggers e rewards versionados, com validação de schema antes de executar.

7. Persistência, segurança e importação

Chaves locais: wmk-world-studio-maps-v1, wmk-world-studio-assets-v1 e dados de missão em chave específica do sistema. O editor limita quantidade e tamanho de objetos/imagens e lê JSON como dados — não executa código fornecido pelo mapa. Não confie em arquivos recebidos de desconhecidos; o limite atual é de protótipo, não um sandbox certificado. localStorage pode perder dados ao limpar navegador; o formato JSON deve ser considerado mecanismo obrigatório de backup.

8. Como adicionar recurso sem quebrar o jogo

  1. Faça cópia do projeto e salve um JSON de cada mapa e do projeto completo.
  2. Defina um campo novo e valor padrão no esquema de objeto/missão.
  3. Atualize sanitizeMap() e a normalização das missões, incluindo versionamento.
  4. Adicione o controle UI com identificação acessível.
  5. Implemente renderização, edição, colisão e exportação/importação.
  6. Teste reabrir projetos antigos, trocar mapas, mover objetos, entrar/sair de veículos e ESC.
  7. Revise desempenho: cache imagens, evite alocações em frames e considere spatial hashing para colisões.

9. Próximos passos recomendados

Separar módulos core/, world/, editor/, missions/ e ui/; implementar grid e snap, desfazer/refazer, seleção múltipla, layers visíveis e bloqueáveis, gizmos de rotação/escala, prévias, visualização de colisores, tilesets, atlas e caminhos de NPCs. Para uma versão web hospedada, guardar JSON em arquivos reais via backend autorizado ou exportar e commitar manualmente; GitHub Pages não é servidor de escrita.

Novidade v1.4 — Bot Lab e arena top-down

JSON do mapa: bots[] com id, name, team, x, y, hp, weapon, damage, range, vision, speed, accuracy, behavior e patrol [[x,y],...]. Cada objeto de objects[] permite solid, rotation, layer, w/h e sprite assetId. O editor de Bots configura guarda, patrulha e perseguidor; equipes red/blue/neutral. O mapa Terminal Zero demonstra cobertura e confronto entre equipes.

Missão: goal=points, eliminate ou survive; kills=0 significa todos os inimigos; time em segundos; maps=[] indica qualquer mapa. Testar com python testes/test_smoke.py; localStorage real não foi validado nesta rodada. 3D não é importado diretamente: converter GLB/FBX para sprites PNG antes.

Novidades v1.5 — Gizmos e World Studio

No menu abra World Studio e selecione um objeto ou bot clicando na cena ou pela lista. G move por alças vermelha (X) e azul (Y). S escala objetos pela alça verde; R gira objetos pela alça roxa. Bots têm movimentação, mas não escala/rotação individual. Marque Grade 25 para alinhamento. Ctrl+Z desfaz e Ctrl+Y refaz operações na cena.

O Editor de Missões agora tem uma tela separada com regras avançadas expansíveis. Para um tutorial com exercícios, limites e planejamento, consulte Guia de evolução v1.5.

Atualização v1.6 — Bots, Objetos e Armas

Seleção de bot: World Studio → Ferramenta → Inserir bot. A janela mostra cartões 🔴 Inimigo, 🔵 Aliado e ⚪ Neutro, com nome, equipe, arma, comportamento e HP. Clique no tipo desejado, depois no mapa, e use o gizmo G para mover.

Editor de Objetos: abra no menu principal; crie modelo com tipo, dimensões, cor, colisão, sprite opcional e camada. Salve e no World Studio escolha a ferramenta «Objeto da biblioteca» para inserir. Modifique instâncias com G/S/R. Cada mapa pode ser duplicado e editado.

Editor de Armas: abra pelo menu principal; crie arma fictícia configurando dano, alcance, cadência, capacidade e precisão. No Bot Lab escolha a arma para preencher os atributos do bot. A cadência influencia os tiros da IA; a capacidade ainda não implementa recarga do bot.

Use Exportar JSON em cada editor e Exportar Projeto no menu para cópias de segurança. As bibliotecas são gravadas localmente no navegador, não em uma conta online.

◉ WMK Avatar Lab — v1.7

Menu principal → EDITOR DE AVATAR. Personalize nome, porte corporal, cabelo, boné/capacete, mochila e cores. A pré-visualização aparece à direita, em Canvas, com o personagem visto de cima.

Salvar avatar aplica a aparência ao jogador em todos os mapas. Exportar JSON gera um backup; Importar JSON preenche a prévia e exige clicar em Salvar. O botão Exportar Projeto também inclui o avatar.

Exemplo JSON: {"format":"wmk-vida-loka-avatar","version":1,"avatar":{"name":"Jogador","body":"regular","hair":"short","hat":"cap","backpack":"pack","skin":"#f2c6a1","shirt":"#50d6a8","pants":"#213740","hairColor":"#342722","hatColor":"#d1b260","packColor":"#5a8191"}}

Para desenvolvedores: funções safeAvatar() (validação), paintAvatar() (desenho), renderAvatarPreview() (prévia); persistência local pela chave wmk-vida-loka-avatar-v1. Não executa scripts de arquivos importados. O formato do corpo modifica apenas o visual, sem alterar colisões nem atributos.

Exercício: crie três avatares, exporte JSON e importe outro modelo. Próximos passos: skins PNG, animações, múltiplos personagens e compartilhamento de visuais com NPCs.
