Manual do Desenvolvedor

WMK Vida Loka • Documentação em português • v1.2.0

1. Arquitetura atual

Aplicação client-side sem build: um único index.html com Canvas 2D, estado de simulação, entrada por teclado, câmera, desenho, HUD e editor de missões. Documentos separados e logotipo SVG.

requestAnimationFrame → update(dt) → updatePlayer / updateMission / updateLaw / updateCamera → render()

2. Arquivos e ambientes

Use servidor estático simples para desenvolvimento: python -m http.server 8000 no diretório, depois http://localhost:8000. Também funciona abrindo HTML diretamente. Use DevTools (F12) para erros.

3. Formato de missão JSON

{
  "id": "entregas",
  "title": "Correio da Confusão",
  "description": "Busque e entregue pacotes",
  "type": "delivery",
  "points": [[760,150], [1360,650]],
  "reward": 800,
  "vehicle": false
}

Tipos suportados: checkpoint, pickup, delivery, race, escape. No protótipo, todos exceto fuga percorrem marcadores; fugir exige despistar a polícia antes do ponto final. Dados validam limites e recompensas; não executam códigos do JSON.

4. Limites da cidade

Mundo 2720 × 2300 unidades de simulação, não metros físicos. Coordenadas aceitas para missões: X de 20 a 2700 e Y de 20 a 2280. A velocidade do HUD é ilustrativa, não uma conversão física.

6. Recomendação de refatoração

Extrair módulos ES: core/game.js, world/map.js, entities/player.js, entities/vehicle.js, missions/mission-engine.js, editor/mission-editor.js, ui/panels.js e storage/save.js. Criar testes unitários de serialização e lógica de missão antes de avançar.

7. Troca de modelos/sprites

Atualmente carros e edifícios são desenhados com primitivas Canvas. Uma futura camada de apresentação deve mapear spriteId para Image ou atlas de sprites e manter geometria/colisão independentes da arte. Para GLB/GLTF 3D, será necessário outro renderizador, portanto não basta apontar o arquivo ao Canvas.

8. Segurança e licença

Não use eval para missões. Valide tamanho, tipos, limites, IDs únicos e versão do schema. Não confunda licença MIT para novas contribuições com permissão automática sobre o código original não identificado. Pacotes Kenney geralmente são CC0, mas verifique licença por download.
