Manual de multisseleção, grupos e prefabs compostos

Walney Moreira Klein — walneyk@hotmail.com

1. Como usar o editor

No menu principal, clique em World Studio. Escolha o mapa e pressione Duplicar mapa para criar uma cópia antes de editar. Na lista de ferramentas selecione um tipo de objeto e clique no mapa para inserir.

2. Seleção múltipla

  1. Escolha Selecionar/mover.
  2. Clique num objeto e mantenha Ctrl ou Shift enquanto clica nos próximos.
  3. No painel de seleção à direita, use Ctrl/Shift para selecionar vários itens da lista.
  4. O contador mostra quantas entidades foram selecionadas.

3. Grupos

  1. Selecione pelo menos duas peças.
  2. Clique em Agrupar seleção; ambas passam a compartilhar um identificador `groupId`.
  3. Arraste uma peça do grupo para deslocar o conjunto.
  4. Use Duplicar seleção para produzir uma cópia, ou Desagrupar para remover a associação.
Os bots podem fazer parte da multisseleção e do movimento, mas nesta entrega o agrupamento persistente é exclusivo de objetos. Escala e rotação múltiplas não estão implementadas.

4. Prefabs compostos

  1. Crie uma construção com dois ou mais objetos, por exemplo uma garagem com paredes, portão e decoração.
  2. Selecione as peças e clique em Salvar conjunto como prefab.
  3. Digite um nome descritivo.
  4. Abra outro mapa, escolha o nome em Prefabs compostos e pressione Inserir conjunto no mapa.
  5. O conjunto é inserido perto da posição inicial do mapa, com IDs novos e posições relativas preservadas.

5. Importação e exportação

Use Exportar biblioteca de conjuntos JSON para transferir modelos. Use Importar biblioteca de conjuntos JSON para adicioná-los. Mapas são exportados no botão JSON superior, separadamente. Salve os dois arquivos para backups completos.

6. Exemplo de formato JSON

{
  "format": "wmk-composite-prefabs",
  "version": 1,
  "prefabs": [{
    "id": "prefab-exemplo",
    "name": "Garagem compacta",
    "objects": [
      {"id":"a", "name":"Parede","type":"barrier","x":-60,"y":0,"w":120,"h":20,"rotation":0,"color":"#6a8e8b","solid":true,"layer":0,"assetId":""},
      {"id":"b", "name":"Portão","type":"barrier","x":60,"y":0,"w":100,"h":20,"rotation":0,"color":"#51778d","solid":false,"layer":0,"assetId":""}
    ]
  }]
}

As coordenadas X/Y neste formato são relativas ao centro do conjunto. A importação valida quantidade de objetos e tamanho do arquivo, trata JSON como dados e não executa scripts nele.

7. Recursos técnicos

studioSelection contém chaves obj:id ou bot:id. Cada objeto agrupado guarda o campo groupId, preservado no JSON do mapa. A biblioteca de conjuntos é salva em localStorage sob a chave wmk-vida-loka-composites-v1. O histórico do editor conserva snapshots de objetos, bots e spawn.

8. Exercício de estudo

Duplique Terminal Zero e monte uma sala com quatro barreiras; selecione e agrupe; crie outra sala duplicando a seleção; salve o conjunto como prefab; abra Serra Brava e insira o mesmo conjunto; exporte mapa e biblioteca de prefabs. Em outro navegador, importe os dois JSONs e confirme o resultado.

9. Limitações e próximas etapas

Ainda são necessários: hierarquia de grupos aninhados, pivot de grupo, gizmos de escala/rotação coletiva, caixa de seleção, camadas bloqueáveis, tilesets reais com autotile, salvamento interoperável com Game Creator e validação de recarregamento em HTTP no Windows. Modelos GLB/FBX precisam de renderização prévia como sprites para uso no Canvas 2D.
