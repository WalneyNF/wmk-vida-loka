Walney Moreira Klein — walneyk@hotmail.com

1. Introdução

O menu Biblioteca & Diagnóstico reúne recursos dos editores. Seu propósito é expor dependências e identificar referências ausentes; não altera dados automaticamente.

2. Como usar

  1. Abra o menu principal.
  2. Clique em Biblioteca & Diagnóstico.
  3. Selecione Mapas, Missões, Bots, Prefabs, Armas, Avatares ou Sprites.
  4. Clique Verificar referências para analisar dependências.
  5. Use Abrir editor correspondente para corrigir itens.

3. Modelo de referências

Mapas → objetos posicionados → sprites
     → bots → armas e avatares
Missões → mapas permitidos
Game Creator → mapas, missões, armas e perfis

4. Núcleo independente

O arquivo js/wmk-core.js fornece WMKCore.inspect(project) para análise, WMKCore.validateBundle(project) para checagem de IDs e WMKCore.makeBackup(project) para gerar um instantâneo. O JSON é tratado como dado, nunca executado como código.

5. Exemplo de prefab JSON

{
  "id": "barreira-001", "name": "Barreira",
  "type": "barrier", "w": 100, "h": 35,
  "solid": true, "rotation": 0, "layer": 1
}

6. Exercícios

  1. Duplique Terminal Zero no World Studio.
  2. Adicione um objeto com colisão e um bot aliado.
  3. Crie perfil de avatar e atribua ao bot.
  4. Abra a Biblioteca e confira as contagens.
  5. Exporte o projeto pelo menu e guarde-o em local seguro.

7. Backup e limites

O backup JSON gerado nesta Biblioteca é de auditoria. Não é um formato restaurável pelo importador atual; para restaurar use Exportar Projeto. O motor e diversos editores continuam no index.html, com modularização gradual. Ainda não há campanha ramificada, multiplayer, animações completas ou jogo independente exportado.

8. Testes

Consulte relatório da v2.1. O teste de navegação HTTP e persistência real após reinício ainda exige validação local no Windows.
